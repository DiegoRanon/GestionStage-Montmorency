# GestionStage-Montmorency 🎓

**GestionStage-Montmorency** est une application web complète développée dans le cadre du programme **Techniques de l’informatique – Application Web** au **Collège Montmorency**. L’application permet aux étudiants, superviseurs et enseignants de gérer efficacement les stages académiques.

Ce projet a été réalisé par une équipe de trois développeurs :
- **Diego Ranon**
- **Chems-Eddine Rebouh**
- **Lucas Riggi-Charbonneau**

---

## 🚀 Fonctionnalités principales

- 👨‍🎓 **Portail étudiant** – Soumettre des candidatures, consulter les offres de stage et suivre leur statut
- 🏢 **Espace employeur** – Publier des offres, suivre les candidatures et évaluer les stagiaires
- 🎓 **Interface enseignant** – Valider les stages, gérer les documents et suivre les progressions
- 📁 **Gestion des documents** – Téléversement et consultation des CV, conventions de stage, etc.
- 📊 **Tableau de bord interactif** – Pour chaque type d'utilisateur avec statistiques et rappels
- 🔐 **Système d'authentification** – Sécurisé avec différents niveaux d’accès (JWT)

---

## 🛠️ Technologies utilisées

- **Frontend** : `React.js` + `Axios`
- **Backend** : `Node.js` avec `Express.js`
- **Base de données** : `MongoDB` avec `Mongoose`
- **Authentification** : JWT (JSON Web Tokens)
- **Outils** : Git, VS Code, Postman, MongoDB Atlas

---

## 🎯 Objectifs du projet

- Appliquer les principes de développement **full-stack moderne**
- Gérer les rôles utilisateurs et les droits d’accès avec une API RESTful
- Travailler en équipe dans un environnement de développement collaboratif (Git/GitHub)
- Structurer un projet selon l’architecture MVC
- Déployer et tester une base de données NoSQL en ligne

## 📂 Comment exécuter le projet

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/your-username/GestionStage-Montmorency.git
   cd GestionStage-Montmorency
   ```

2. Lancer le **backend** :
   ```bash
   cd backend
   npm install
   npm start
   ```

3. Lancer le **frontend** :
   ```bash
   cd frontend
   npm install
   npm start
   ```

4. L’application sera disponible sur `http://localhost:3000`.

> ⚠️ N’oubliez pas de configurer votre fichier `.env` pour connecter l’API à MongoDB.
